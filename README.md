■実情調査と落とし穴
本来、SBもPBも時間をかけて徐々に拡大させてゆくものである。従って計画段階から鳴り物入りでマスコミに発表して、さらに数一•店で一斉に発売を開始するなど、無謀な話である。
売価がこれまでより革新的に低いといった決定的な長所があるのなら、人気が出る可能性もあるだろう。しかし売価は少し安い程度で、デザイナーやバイヤー個人の感性頼みでは、客の支持を得られる保証は皆無である。それでは博打と同じだ。
賭け事は儲けるよりも損をすることの方が多いものなのである。
欧米のチェーンストア業界では、新商品の導入には科学的な手順を踏むことが常道になっている。あらかじめ決められた手順を踏んで周到に準備をし、一歩一歩進めながら、商品開発を確実に成功へと導く流れが必要なのである。
PBとは、チェーンストア各社の独自規格品である。従って、わが社の客がその時期に欲しいと思う商品を、タイムリーに生産し販売しなければならない。それにはまず、情報収集システムを確立しなければならないのである。
もともと商品の人気は一部の品種と品目に集中するのが常識である。どれもが平均的に売れたためしはない。だからこそ、他社が扱う多くの※トレンド品の中から人気の高い要素だけをえりすぐり、新たに品質を決め直して商品化する技術が不可
久なのである。
日本ではいまだに、「バイヤーや店長、販売員自身の個人的な好みで、売りたいものを売る」、または「デザイナーが街を歩く若者の服装からヒントを得てデザインした」など、なんの数字の根拠もなく、個人の感覚を頼りに商品の仕入れや調達を行う習慣がある。しかしそれでは、やはり目論見が外れる場合が多く、企業の規模拡大はかなわないのである。
最初に収集すべき情報は、まずわが社の過去の販売数量実績である。POSデータを見れば、わが社の売れ筋品目が分かる。
しかしそこで間題になるのは、わが社のPOSデータには”わが社がかつて仕入れた商品についての販売実績”しか出てこないことである。最初からわが社が売れ筋商品を仕入れていなければ、それまでなのだ。仮に売れ筋商品があったとしても、途中で品切れしたのなら売れた数量は大した量ではない。その場合、在庫を十分に持っていた他社では売れ筋になったとしても、わが社では売れ筋にならないのだから、わが社のPOSデータの販売実績の上位には出てこないのである。

①のような大チェーンストアでは、売れ行き見込みが不確実なトレンド商品をわないのが常である。だからトレンド情報を入手するために、将来人気が出てホトになる確率の高い商品を扱う②を定期的に調査する。今後の商品企画の参考にするためである。価格の点で我々はそれを扱うことはできないが、トレード・オフのきっかけを提供してくれることが多い。
たとえば売れ筋予測が最も難しいといわれている服飾の場合、ZaraやH＆Mなどのトレンド商品に強い大チェーンストアや、デザイナーブランドを扱うサックス・フィフス（Saks Fifth）やニーマン・マーカス（Neiman Marcus）といったファッション・リーダー・ショップ（FLS）がその調査対象となる。
ニューヨークの五番街に本店を構えるSaks Fifth の売場には、月曜日の午前中に各社のバイヤーや調査員が詰め掛ける。週末に売れた商品の陳列量を調べるためである。この時にサイズ切れを起こしている商品は、売れた証明になるわけだ。
いずれの場合も、他社の扱い商品から売れ筋を発見するには、感覚的に選んではいけない。重要なのは数値で、数えることである。陳列量と販売量の多い商品を見つけるのだ。後者は補充日と月曜日との陳列量の引き算でわかる。つまり、週二回は同じ店を調べるということである。
▫️売れ筋サンプルの蒐集
数字的な根拠に基づいて証明できる売れ筋商品については、必ずそのサンプルを入手する。色違いがあれば、すべての色を漏れなく購入すること。決して調査者の個人的な好みや感性で選択してはいけないのだ。さらにその中でも、陳列量の多い売れ筋の色を最低三枚以上は購入することである。その後科学的な検査に出したり、生地のソーシングや仕様書をつくるために分解したり、ベンダーに見せるために持ち歩いたり、貸し出したりと、様々な用途に対応しなければならないからだ。サンプルは一枚、一個では用が足りないのである。
海外の大チェーンストアなら、売れ筋を突き詰める技術力が高いため、陳列量の多い商品は販売量も多い。だから各社が一品大量陳列している品だけを、片っ端からすべて買い集めてゆけば、売れ筋の傾向がほぼ確実にわかることになる。
同時に、わが社の※ベーシックアイテムと用途が一致する商品なら、ラベルを変えてそのままわが社で試売するために、一二枚（個）以上購入するのが原則である。
服飾の場合、春物は二月前半、秋物は七月後半あたりから新商品が出そろう。その時期にこのようなサンプル蒐集に出かければ、大きな成果が得られるはずである。
その点、日本の従来型店舗を調べに行っても、売れ筋がわかりにくい。ちょっとずついろいろと置いてあって、品揃えに品目間の強弱がないからである。同業者に分かりにくいということは、客にはもっと分かりにくい。そのことも大問題である。
それでも、代表的企業の店舗を何店も調べれば、その共通項が分かってくる。
一方、日本に進出している欧米のアパレルチェーンは、売れ筋を必ずクローズアップしているから、定期的に定点（同一店舗での）調査を繰り返すべきである。サンプル入手も同様である。
商品サンプル入手などのための予算は、あらかじめ開発費として計上しておくものだ。交通費などの旅費も同様である。「貧すれば鈍する」ということわざのごとく、使える経費が少ないと、得られる情報も少なくなる。PBづくりに成功しているチェーンストアの多くは、トップ自身が、商品開発の指揮を執ってきた。予算が自由に使える状況にあったことが、商品開発成功の鍵だったのだ。
マーチャンダイジングチームのメンバーは、こうして蒐集した商品見本、そしてスケッチ画、写真、生地見本、さらには数表を添付した企画書を各自が持参して、月曜日の夕方に本部に集合する。服飾に限らず、非食品の商品は週末に大量に動くから月曜日は忙しいのだ。早朝に前週のPOSデータを分析し、その結果を踏まえて他社のストア・コンパリゾンに出かける。午後はその湖査結果に基づいた企画書を完成させた後に、夕方からの商品企画会議に臨むのである。
会議では、参加者全員が売れ筋要素の一つ一つについて発言を求められる。そこでの討論は、確たる根拠に基づいていなければならない。そのために数字の裏付けが必要なのである。日本では好き嫌いや感覚的な説明で企画を通す習慣があるため、売れ筋が育たず、死に筋が増えるのである。
2.試売の重要性
■試売のすすめ
会議で企画が通ったからといって、すぐにマス生産態勢に入るのではない。まず試験販売（試売）用の試作品をつくり、マス化できることを確かめるのである。
その商品が売れるかどうかは、売ってみなければわからないものである。過去の販売データや他社で売れている商品であっても、全く同じ商品で同じ環境ではない以上、確実に売れる保証はない。だから試売を実施するのである。
一店で一つや二つ売れればいいのなら、試売の必要はない。また数百個（枚）、数千個（枚）の見込み生産した商品を全店に分散して売り切って終わりにするならば、それでもいい。
しかし、チェーンストアの人気を高め、商品開発で固定客を増やすという目的のためには、マス化商品の育成が不可である。
それは毎シーズン確実に売れる息の長い※クラシック商品と、短期に爆発的に売れるホット商品の両方である。店数が三桁以上のチェーンストアなら、一品目で年間数十万個（枚）から数千万個（枚）を販売する商品である。だからこそ商品開発に、時間と費用を十分にかける値打ちがあるのだ。
そのためにはマス生産に値する商品を、試売によって早期に発見しなければならないのである。
生産のリードタイムは年々短縮されている。グローバルな配送システムとコンピュータの発達で、生産拠点が世界のどの大陸にあろうと、原材料の手当てさえ事前にできていれば、発注から納品まで二週間以内でできるようになった。いまだに六カ月前発注を要求されているならば、その企業は生産者にとって優先的な取引先ではないということだ。
日本の多くの小売企業が、いまだに生産者側から六カ月前発注を義務付けられているのは、工場にとってはほかに大量発注をしてくれるお得意がいて、そちらの売れ筋追加生産の割り込み余地を見込んでの場合が多い。つまり生産ラインが空いているときに、お得意でない日本の企業の商品をつくろうとしているのである。
生産者がそう目論むのも無理はない。工場にとっては、同じ商品を大量に生産する方が、楽で利益率も高いからである。だから初期発注のロットが大きく、さらに追加発注してくれる企業こそがお得意なのである。
一方、日本の小売企業は多品目少量生産が前提の上、根拠が薄弱な見込み発注だけで追加発注はしない慣習なので、軽視されるのは無理のないことである。
試売システムさえ確立すれば、シーズン直前の試売で売れ筋を確定することができ、大量発注も可能になる。マス生産に十分間に合う短期間での納品システムを構築することこそ売れ筋商品育成の決め手である。
■ゾーン単位の試売
試売については、全国チェーンならかなり正確な数字が出せるはずである。地域間の気温差を利用して、自社の店舗で試売ができるからだ。
日本の国土は狭いとはいっても、気象庁が予め発表している気温比較図でもわかるとおり、北と南の温度差は春で八週間、秋で七週間もある（図表512参照）。
従って、全店一斉に同一品目の発売を開始するのは大きな間違いである。試売後も気温の変化に従って、徐々に商品の投入時期を変えていくことで、売れ筋の把握が確実になるからである。その結果販売量を増やすにしても減らすにしても、生産調整がまだできるから、値引き
ロスと機会損失とを最小にとどめることができる
のだ。全国チェーンではない場合、わが社の大商圏型店舗で試売を実施する。
多くの来店客が地理的に広範囲から集まる店には初物好きな客の来店確率も高くなるから、売れ筋傾向の初期把握には便利である。
欧米から日本に進出している服飾チェーンの東京都心店で、八月の暑いさなかにツイードのコートを扱うのは、先物買いをする客がいるからである。売れ筋情報を提供してくれる初物好きな客はそれほど多くない。しかし、大商圏だからこそ客数が多く、その中には今すぐ着るわけではないが、どうしても欲しいから今のうちに買っておきたいという特殊な客が混じっている確率が高くなるのだ。
サンプル数が多ければ多いほど売れ筋が判る確率が高くなることは当然だが、少ないサンプル数でも、バイヤー一人の当てずっぽうよりははるかにましである。
試売用の商品は、売場の特に目立つ位置に陳列する。早く結果を出すため主通路沿いの第一磁石売場、または第三磁石売場を試売用に割り当てる。陳列量は多くなくても、フェイシング数は必ず増やす。つまり、商品がひと塊で客の目に飛び込んでいくように仕向けるのだ。色別の売れ行きを調べるためには、フェイシング数を同一にそろえて並列に並べる。同じ条件で比較することで、調査結果が確実になる。
試売のための試作品は一〇〇個（枚）前後必要である。少なくとも三店で試売を実行したいからである。マス生産と同じ工場で生産する方法もあるが、時間の問題から見ると、これだけは国内の工場を使う方法もある。欧米のチェーンストアなら、（作品専門の工場を本部の近くに別に持っている場合もある。また航空エキスプレ（便を上手に活用する方法もある。
先に述べた通り、試売にも段階がある。商品企画の対象になるかどうかを調べる
＊一段階の試売は、一店で行う。一〇枚（個）ほどで結果を出せる。他社の商品のベルを替えてわが社で売ってみるのは、この段階である。
もちろん少量の試作品で試してみる場合もある。しかしこれには、客の目に付くけの量がないと注目してもらえない。その場合は最低六枚（個）は必要だろう。
この時点では、売れたかどうかよりも、客がその商品のどこに興味を示したかを察することが狙いである。
ーパワーテストの活用
試売で売れ筋と証明された商品はマス生産態勢に入るわけだが、一方ではパワーアストを実施したい。毎回行う必要はないが、扱いなれない品種や、競合の関係が変化したときなどに実施する。
異なる商勢圏に位置する、商圏人口がほぼ同一の標準的経営効率の店舗を選び、店舗ごとに売価を変えて、試売するのである。わが社の価格政策の範囲内で最大のマーケットシェアが取れ、しかも最大の荒利益高が確保できる売価がいくらなのかを発見することが目的である。商勢圏の異なる店舗を選ぶのは、同じ客が両方の店には来ないはずだからである。これは同じ商品の売値が異なるので、混乱を避けるためである。
このパワーテストでは第一に、いったいいくらで売れば最大の荒利益高を確保できるかを調べる。普通、値段を安くすれば一つあたりの荒利益高は減るが、販売量は増える。しかし品種によっては、ある売価を切ってさらに安くしても販売量が増えない場合がある。
そのバランスで、合計荒利益高が最大限確保できる売価を見つけ出すのである。
もちろんわが社の価格帯の範囲内でである。そのためには、なるべく同じ条件の三店を選ぶことがポイントになる。
パワーテストの第二の目的は、見切り価格を決めることだ。いったいいくらにすれば爆発的に売れるのか、見定めるのである。
売れ筋なら、もちろん売れ続けている限り追加生産をして補充する。しかし季節
品の場合、最後に残った商品を効率よく売り切るための売価も、知っていなければならない。それは試売結果どおりに売れず、予測販売量を下回った場合の見切り価格でもある。
客が買いたい商品の価格と品質の特性は、いずれもある程度までの予測は可能である。そこまでは間接的な情報収集で突き詰められる。しかし試売でしか、本当の数量はわからないものなのだ。まずは、ベーシックアイテムのスタイルやカラーや味の種類をマス生産前に試売すること。それによってスタイル数や色数や味の種類を減らすことから始めよう。
これまでの八色扱いを四色に、そして二色へ、売れ筋だけを扱う。そしてそれぞれの販売量に見合った数量を確保しよう。売れ筋でもそれぞれが平均的に売れるはずはない。そうすれば死に筋と、POSデータには出てこないほう大な機会損失が防げるはずである。
科学的に販売数量予測技術を研鑽すれば、精度は徐々に高まるのである。
試売は開発商品だけの問題ではない。仕入れ商品でも条件は同じである。逆に仕入れ商品こそ、契約前ならいくらでも入れ替えがきく。売れ筋になって追加したい時に今取引しているベンダーが在庫を持っていなければ、他社を探して数量確保もできるのである。
